# מטענים חיפה LIVE — גרסת בסיס

החבילה כוללת מסך תצוגה של 8 שקופיות:

1. פתיחה
2. נהג החודש
3. מחירון המרכולית
4. ימי הולדת
5. תמונת השבוע
6. פינת החיוך
7. הודעות
8. סיום

## בדיקה במחשב

יש להפעיל את התיקייה דרך שרת מקומי. פתיחה ישירה של `index.html` עלולה למנוע מצב אופליין.

ב-Windows, כאשר Python מותקן:

```bash
python -m http.server 8080
```

לאחר מכן פותחים בדפדפן:

```text
http://localhost:8080
```

## מה עובד כבר עכשיו

- מעבר אוטומטי בין כל השקופיות
- אנימציות ללא סאונד
- מונה שקופיות
- מצב חיבור
- שורת "עודכן לאחרונה"
- שמירת כל הנתונים ב-localStorage
- Service Worker ששומר את קובצי האפליקציה לעבודה אופליין
- נתוני דוגמה מקומיים

## חשוב לגבי אופליין

מצב אופליין עובד לאחר שהאתר נטען לפחות פעם אחת דרך כתובת HTTP/HTTPS.

כאשר נחבר Google Sheets:
- בחיבור תקין יישמר כל המידע החדש.
- ללא אינטרנט יוצגו כל השקופיות מהעדכון האחרון.
- כשהאינטרנט יחזור, המערכת תנסה להתעדכן לבד.

## השלב הבא

ניצור Google Apps Script שממיר את הגיליונות שכבר בנית ל-JSON.
לאחר הפרסום, נכניס את הכתובת לתוך `config.js` בשדה:

```javascript
DATA_URL: "כאן תיכנס כתובת האפליקציה"
```


## פס חדשות רץ
ב-Google Sheets הוסף בהגדרות שדה בשם `news`.
כתוב כמה הודעות באותו תא והפרד ביניהן באמצעות הסימן `|`.

דוגמה:
```
📢 מחר תרגיל בטיחות בשעה 09:00 | 🎂 מזל טוב לניר | 🚂 משמרת טובה לכולם
```

פס החדשות נשאר קבוע בתחתית המסך וממשיך לרוץ בזמן שהשקופיות מתחלפות.
